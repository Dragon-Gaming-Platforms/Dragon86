# public/arch64-x11 — vendored guest pack (xgfx64)

Built by the 'Build arch64 guest' workflow (tools/xgfx64-collect.sh) —
not written by hand. Arch Linux x86_64 binaries as shipped, collected
with their library closure; kernel modules are for 6.18.60-1-lts (the same
kernel public/arch64 ships). Installed by the App Store into the OS
filesystem's /, then finished inside the machine: sh /install-wm64.sh
